# Rotating Objects

Lua Trigger lets you interact with objects through group IDs. One of the ways you can interact with objects is by rotating them. An example of how to rotate objects is below:

```lua
while true do
    Object.rotate(
        2,  -- Target group ID
        1,  -- Center group ID
        90, -- Degrees
        0,  -- Times to rotate 360 degrees
        1,  -- Duration
        0,  -- Easing type
        2   -- Easing rate
    )
    wait(1) -- Waits 1 second (look at wait docs)
end
```

The code above rotates all the objects in group ID 1 90 degrees over 1 second.
