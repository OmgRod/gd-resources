# Scaling Objects

Lua Trigger lets you interact with objects through group IDs. One of the ways you can interact with objects is by scaling them. An example of how to scale objects is below:

```lua
while true do
    Object.scale(
        5, -- Target group
        1, -- Center group
        2, -- Scale X
        2, -- Scale Y
        1, -- Duration
        0, -- Easing Type
        2, -- Easing Rate
        {  -- Options
            relativeScale = true
        }
    )
end
```

The code above scales group 5 to 2x size with center group ID 1 over 1 second.
