# Adding Dialog

The `Dialog` API allows you to trigger Geometry Dash's native cutscene dialogue system directly from your Lua scripts. When a dialogue opens, player movement is automatically paused until the dialogue sequence finishes.

## Basic Usage

To present a dialogue sequence, pass an array of speech frames to `Dialog.show()`.

```lua
-- Example: Shop entry dialogue sequence
Dialog.show({
    {
        speaker = "Scratch",
        text = "Hello player!",
        avatar = 8,
        scale = 1.0,
        unskippable = false
    },
    {
        speaker = "Scratch",
        text = "Goodbye player!",
        avatar = 9
    }
}, {
    bgType = 2,
    animateSide = true
})
```

## API Reference

### `Dialog.show(dialogList, [options])`

Displays a sequence of interactive dialogue boxes.

#### Arguments

1. **`dialogList`** (`table`): An array table where each element is a table containing the setup for an individual dialogue box.
2. **`options`** (`table`, optional): A configuration table controlling overall dialogue presentation.

## Text Formatting Tags

Geometry Dash uses built-in text tags within dialogue strings to trigger color shifts, speed adjustments, and sound effects:

* **Text Speed:** `<d030>` changes text delay (e.g., `030` = 0.30s per letter).
* **Color Tags:** `<cr>` (Red), `<cg>` (Green), `<cb>` (Blue), `<cy>` (Yellow), `<co>` (Orange), `<c#HEX>` (Custom Hex Color).
* **Reset Color:** `</c>` resets text color back to default white.
* **Sound Effects:** `<s100>` plays a specific GD sfx ID when that word appears. `</s>` stops/resets current text sound settings.
