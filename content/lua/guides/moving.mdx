# Moving Objects

Lua Trigger lets you interact with objects through group IDs. One of the ways you can interact with objects is by moving them. An example of how to move objects is below:

```lua
while true do
    Object.move(
        1, -- All objects in group ID 1
        30, -- Moves object 30 units (1 block) to the right
        30, -- Moves object 30 units (1 block) up
        1 -- Over 1 second
    )
    wait(1) -- Waits 1 second (look at wait docs)
end
```

The code above moves all the objects in group ID 1 30 units up and 30 units right over the duration of 1 second.
