# Player Control

The `Player` API allows you to directly interact with and control the player characters during gameplay.

## API Reference

### `Player.kill([playerType])`

Destroys the specified player instance, triggering the death/respawn sequence for the current layer.

#### Arguments

1. **`playerType`** (`integer`, optional): An integer enum specifying which player character to destroy. Defaults to `1` (`Player.Player1`).

## Basic Usage

### Instant Death

To immediately destroy Player 1 (the default action):

```lua
-- Kills Player 1
Player.kill()

-- Explicitly passing the enum
Player.kill(Player.Player1)
```

### Dual Mode Targeting

When working in Dual Mode, you can target specific players or destroy both at once:

```lua
-- Destroy only Player 2
Player.kill(Player.Player2)

-- Destroy both Player 1 and Player 2 simultaneously
Player.kill(Player.Both)

```
