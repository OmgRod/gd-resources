## Easing Rate

When using an **Easing Type** other than `None` (0), the **Easing Rate** controls the intensity or acceleration curve of the easing animation. 

In Geometry Dash, the easing rate acts as a multiplier/exponent for the easing formula:

* **Default Value:** `2.0` (Standard GD easing curve)
* **Minimum Value:** `0.1` (Flattens the curve, making movement almost linear)
* **Higher Values (`> 2.0`):** Makes the easing effect much more aggressive (e.g., faster acceleration at the start, sharper deceleration at the end).

In functions like `Object.move()`, `easingRate` is passed as the **6th parameter** (optional, defaults to `2.0`):

```lua
-- Move Group 1 by (100, 50) over 1.5s using EaseInOut (1) with an aggressive rate of 4.0
Object.move(1, 100, 50, 1.5, 1, 4.0)

-- Standard Move using SineInOut (13) with the default rate (2.0)
Object.move(2, -30, 0, 0.5, 13)
```
