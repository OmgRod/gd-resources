# Setting up Lua Trigger

Welcome to Lua Trigger! This tutorial will show you how to install the mod and add your first Lua Trigger to a level.

## Installing Lua Trigger

Before you can use Lua Trigger, you need to install the mod through the Geode mod loader.

You can download Lua Trigger from the Geode website:

https://geode-sdk.org/mods/omgrod.lua-trigger

Alternatively, you can install it directly through the Geode mod menu:

1. Open Geometry Dash with Geode installed.
2. Open the Geode Menu.
3. Go to the Download tab.
4. Search for "Lua Trigger".
5. Install the mod and restart Geometry Dash if prompted.

Once Lua Trigger is installed, you are ready to create your first script.

## Adding a Lua Trigger

To add a Lua Trigger to your level:

Open the Level Editor.
Open the Triggers tab.
Look for the trigger with the Lua logo and the name "Lua".
Click it and place it anywhere in your level.
Select the trigger and click "Edit Object" on the right side of the editor.

If everything was installed correctly, you should see the Lua Trigger editor appear.

Congratulations! You have successfully set up Lua Trigger.

In the next tutorials, we will go through how to write Lua scripts, use the built-in functions, control objects, create animations, and make more advanced systems for your levels.
